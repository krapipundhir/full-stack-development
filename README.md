# full-stack-development
Structured journey in Full Stack Development — covering frontend, backend, and databases with Java as the base language.

This repository is a structured learning journey covering the foundations of **Full Stack Development**.  
It includes practice code, notes, and mini-projects across:

- **Frontend**: HTML, CSS, JavaScript, React  
- **Backend**: Node.js, Express, Java (Spring basics)  
- **Database**: MySQL, MongoDB  
- **Extras**: Git, deployment experiments, documentation  

The goal of this repo is to build a solid foundation in web technologies and gradually progress towards **full-stack development**.  
It reflects my step-by-step learning process and growth as a developer
